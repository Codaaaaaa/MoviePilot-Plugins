# MoviePilot-Plugins

### 使用

添加 https://raw.githubusercontent.com/Codaaaaaa/MoviePilot-Plugins/main/ 到 PLUGIN_MARKET

---

### [Discord 消息推送插件](plugins.v2/discord/README.md)

通过 Discord webhook 推送 MoviePilot 的消息到 Discord 频道，并支持 Discord Bot 订阅等命令。

基于 [HankunYu/MoviePilot-Plugins](https://github.com/HankunYu/MoviePilot-Plugins) 中的 Discord 插件重写，沿用 GPL-3.0 许可证。
